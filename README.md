# MNIST GAN

A simple Generative Adversarial Network built using PyTorch
to generate handwritten digits.

## Architecture

Generator:
100 → 256 → 512 → 1024 → 784

Discriminator:
784 → 1024 → 512 → 1

## Dataset

MNIST

## Framework

PyTorch

## Results

Generated handwritten digits from random noise.
